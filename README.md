# Python Physics Simulations

A collection of physics and simulations created in Python to model motion, forces, energy systems, and orbital mechanics.

## Topics
- Pendulum motion
- Orbital mechanics
- Conservation of energy

## Tools Used
- VPython

# Setup and Execution

## Requirements
- Python 3
- VPython

## Install Dependencies

```bash
pip install vpython
```

## Run a Simulation

```bash
python pendulum_simulation.py
```

Replace the filename with any simulation file in the repository.
